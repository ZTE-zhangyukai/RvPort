## 5. 过程中发现并修复的缺陷（本报告覆盖期间）

| # | 缺陷 | 影响 | 修复 |
|---|---|---|---|
| D-01 | `migrationRunId` 装配路径恒 null → git 模式生产从不激活 | 历史三端点对真实运行恒 409 | 改为 `run()` 参数，运行时注入（`51c7e18`） |
| D-02 | API 容器未挂 workspace → 历史端点看不到仓库 | 同上 | compose 补挂载（`51c7e18`） |
| D-03 | reflog 回滚后去重取先见条目 → first-init 标签丢失 | 历史显示"未分类提交" | 去重改为保留可解析四元组的条目（`51c7e18`） |
| D-04 | compose 滚动重启窗口任务竞态（3 次卡 DLQ） | 基础设施既有行为，非本次引入 | 重发即恢复；测试时序上等 worker 就绪后再发起 |

## 6. 结论与遗留

**结论**：AI 迁移 git 历史能力（8 个接口）在真实部署栈上**全部通过**验证——正常路径（创建/执行/历史/产物/回滚）与异常路径（鉴权/路径安全/可达性/参数校验）行为均符合规格（change `add-ai-migration-git-history`）。

**遗留（不阻塞本次验收）**：
1. 前端尚未消费 history/repo-file/rollback 三端点与新产物 kind（提案已界定为后续前端迭代）；
2. 归档候选 diffStat 口径切换（tasks 3.2）未做；
3. 2 条已知偶发测试对建议后续专项治理（测试顺序相关）；
4. compose 重启窗口的任务竞态属基础设施既有问题，建议另立观察项。

**测试数据**：本报告全部响应/提交哈希/产物字节数均为线上实测原值，traceId 可在 `rvport-backend-1` 容器日志中对应检索。
